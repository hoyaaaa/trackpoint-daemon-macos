# Windows reference images

`keyboard-windows.png` and `f12-windows.png` are lossless format conversions of
bitmap resources 212 and 252 from Lenovo's ThinkPad TrackPoint Keyboard II
Windows package 1.0.8.06241 (`ADDPage.dll`). Original imagery is copyright
Lenovo/Chicony; the repository's MIT license does not apply to this imagery.

Installer SHA-256: d14fc7c06306db52fb9c0b01b50efdba0b89dfdae6f75d9ff22bf5198189b3c5.
No Windows executable code or DLL is included in the app or repository.
